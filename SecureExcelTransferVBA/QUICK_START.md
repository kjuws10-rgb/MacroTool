# 1분 사용법

관리자가 설치와 승인을 끝낸 `.xlsm` 파일을 사용하는 방법입니다.

## 가져오기

1. 승인된 `.xlsm` 파일을 엽니다.
2. `Secure Transfer` 화면에서 **파일 선택하고 가져오기**를 누릅니다.
3. 승인 폴더 안의 XLSX 또는 CSV 파일을 고릅니다.
4. XLSX라면 가져올 셀 범위를 마우스로 드래그하고 **확인**을 누릅니다.
5. 대상 문서에서 비어 있는 시작 셀 하나를 클릭하고 **확인**을 누릅니다.
6. 완료 메시지가 나오면 끝입니다. 문서는 자동으로 저장됩니다.

CSV는 전체 파일을 가져오므로 원본 범위 선택 단계가 없습니다.

## 꼭 기억할 점

- 대상 범위는 완전히 비어 있어야 합니다.
- 원본과 대상은 관리자가 승인한 폴더와 파일이어야 합니다.
- 기존 데이터, 수식, Excel 표와 겹치면 안전하게 중단합니다.
- 정책 또는 권한 오류가 나오면 다른 방법으로 재시도하지 말고 IT 보안팀에 문의합니다.
- 사용 가능한 승인 폴더와 만료일은 **승인 상태 확인** 버튼에서 볼 수 있습니다.

## 시작 화면이 안 보이면

- 파일을 닫았다가 다시 엽니다.
- Excel 상단의 **콘텐츠 사용**을 임의로 누르지 말고 조직의 서명된 매크로 정책을 따릅니다.
- 관리자에게 `SecureTransferAdminSetup.bas` 초기화와 `ThisWorkbook` 이벤트 설치 여부를 확인해 달라고 요청합니다.
