# 보안팀 검토 체크리스트

## 1. 업무 및 정책 승인

- [ ] 원본 데이터 소유자와 대상 데이터 소유자가 이전을 승인했다.
- [ ] 원본·대상 보안등급 및 개인정보/영업비밀 포함 여부를 확인했다.
- [ ] Excel 개체 모델을 이용한 값 가져오기가 NSD DRM/DLP 정책상 허용됨을 확인했다.
- [ ] 차단된 붙여넣기를 대신하기 위한 비공식 우회 수단으로 사용하지 않음을 승인서에 명시했다.
- [ ] 승인자 또는 변경 티켓과 승인 만료일이 설정값과 일치한다.

## 2. 경로 및 접근제어

- [ ] `AllowedRoot`가 업무에 필요한 최소 범위의 정확한 폴더다.
- [ ] `ApprovedWorkbookFullName`이 배포 대상 파일의 실제 전체 경로와 일치한다.
- [ ] 승인 폴더에 NTFS/SMB 최소권한 ACL이 적용되어 있다.
- [ ] 승인 폴더에서 재분석 지점, 정션, 심볼릭 링크를 통한 경로 이탈을 차단하거나 별도로 검증했다.
- [ ] 승인 루트가 로컬 동기화 클라이언트나 비승인 외부 저장소로 복제되지 않는다.

## 3. 코드 및 배포 무결성

- [ ] `SecureTransferAdminSetup` 모듈이 운영 파일에서 제거되었다.
- [ ] VBA 프로젝트가 조직의 유효한 코드서명 인증서로 서명되었다.
- [ ] 서명 후 코드나 `ThisWorkbook` 이벤트가 변경되지 않았다.
- [ ] 단말 정책에서 신뢰된 게시자의 서명된 매크로만 허용한다.
- [ ] VBA 프로젝트 잠금과 Excel 구조 보호가 보조 통제일 뿐이라는 점을 수용했다.
- [ ] 운영 배포본의 해시 또는 패키지 버전을 변경관리 시스템에 기록했다.

## 4. 데이터 처리 검토

- [ ] 원본 확장자가 `.xlsx` 또는 `.csv`로 제한된다.
- [ ] `.xlsx`는 읽기 전용, 링크 업데이트 없음, 매크로 실행 강제 차단 상태로 열린다.
- [ ] 외부 데이터 연결이 있는 `.xlsx`는 거부된다.
- [ ] 원본 수식 대신 값만 대상에 기록된다.
- [ ] 대상은 표시 상태, 비보호, 빈 범위이고 기존 데이터 덮어쓰기를 허용하지 않는다.
- [ ] 수식 주입 방지 처리와 기록 후 수식 셀 검사가 요구 수준에 맞다.
- [ ] CSV 인코딩이 실제 승인 파일과 일치한다.
- [ ] `MaxRows`, `MaxColumns`, `MaxCells`, `MaxFileMB`가 업무 최소 범위다.
- [ ] 메모리 부족, 대용량 파일, 잘못된 CSV 따옴표 사례를 시험했다.

## 5. DRM/DLP 및 실패 처리

- [ ] Microsoft 권한 관리가 적용된 원본·대상은 거부되는 동작을 시험했다.
- [ ] NSD 또는 다른 서드파티 DRM 파일의 판별 한계를 문서화했다.
- [ ] NSD 차단이 발생하면 우회·재시도하지 않고 사용자에게 예외 승인 절차를 안내한다.
- [ ] 파일 열기, 읽기, 감사 로그 쓰기, 저장 실패 시 대상 범위가 되돌려진다.
- [ ] 실패 후 대상 파일이 미저장 상태로 남는 예외 상황의 사용자 대응 절차가 있다.

## 6. 감사 및 운영

- [ ] 감사 로그에는 원본 파일명, 대상 파일명, 처리 시각, 행 수만 남는다.
- [ ] 실제 셀 내용, 전체 경로, 사용자 입력 데이터가 감사 로그에 기록되지 않는다.
- [ ] 감사 로그의 보존기간, 접근권한, 위변조 탐지 방법을 조직 정책으로 정했다.
- [ ] 대상 파일의 정상 백업과 복구 절차가 있다.
- [ ] 승인 만료 시 재승인·재봉인·재서명 절차가 있다.
- [ ] 사용자에게 파일 이동·이름 변경 시 승인이 무효화됨을 안내했다.

| 번호 | 테스트 | 기대 결과 |
|---|---|---|
| T01 | 승인 루트의 정상 `.xlsx`, 빈 대상 범위 | 값 기록, 감사 로그 1행, 자동 저장 |
| T02 | 승인 루트의 정상 UTF-8 CSV | 전체 CSV 값 기록, 감사 로그 1행 |
| T03 | 승인 루트 밖 파일 | 기록 없이 중단 및 보안팀 안내 |
| T04 | 대상 파일 이름 또는 위치 변경 | 설정 검증 실패, 기록 없이 중단 |
| T05 | 승인 만료일 경과 | 기록 없이 중단 |
| T06 | 설정 셀 또는 검사값 변경 | 무결성 검증 실패, 기록 없이 중단 |
| T07 | 기존 값이 있는 대상 범위 | 덮어쓰기 없이 중단 |
| T08 | 외부 연결이 있는 `.xlsx` | 기록 없이 중단 |
| T09 | 수식처럼 시작하는 텍스트 | 텍스트로 안전하게 기록되거나 수식 감지 시 전체 중단 |

| T11 | NSD 정책으로 접근 거부 | 다른 경로를 시도하지 않고 중단 |
| T12 | 행·열·셀·파일 크기 한도 초과 | 기록 없이 중단 |
